# AI Resume & Interview Strategy Builder

An intelligent career preparation platform that analyzes resumes and job descriptions using Google Gemini AI to generate custom interview strategies, technical & behavioral questions, skill gap analysis, and tailored roadmaps.

---

## Architecture Overview

- **Backend**: Node.js & Express 5 API with MongoDB (Mongoose), JWT-based authentication via HTTP-only cookies, Google Gemini 2.5 Flash for AI analysis, ImageKit for avatar storage, and PDF parsing.
- **Frontend**: Single Page Application built with React 19, Vite, Sass, React Router 7, and Axios.
- **Containerization**: Dockerfile configured for containerized deployment.

## Environment Variables

### Backend (`backend/.env`)

Copy `backend/.env.example` to `backend/.env` and provide your credentials:

| Variable | Description | Example / Default |
| :--- | :--- | :--- |
| `PORT` | HTTP server listening port | `3000` |
| `CLIENT_ORIGIN` | Allowed client origin for CORS | `http://localhost:5173` |
| `MONGO_BD_URL` | MongoDB connection URI | `mongodb+srv://<user>:<password>@cluster.mongodb.net/resume_ai` |
| `JWT_SECRET` | Secret key for signing session tokens | `your_super_secret_jwt_key` |
| `GOOGLE_API_KEY` | Google Gemini API Key | `AQ.Ab...` |
| `IMAGE_KIT_PRIVATE_KEY` | ImageKit private API key | `private_...` |
| `IMAGE_KIT_URL_ENDPOINT` | ImageKit endpoint URL | `https://ik.imagekit.io/your_id` |

### Frontend (`frontend/.env`)

Copy `frontend/.env.example` to `frontend/.env`:

| Variable | Description | Default |
| :--- | :--- | :--- |
| `VITE_API_BASE_URL` | Base URL of backend API | `http://localhost:3000` |

## Getting Started

### Prerequisites

- Node.js (v18+ recommended)
- MongoDB database (local or MongoDB Atlas)
- Google Gemini API Key
- ImageKit account (for optional user avatar storage)

### 1. Backend Setup

```bash
cd backend
npm install
cp .env.example .env
# Edit .env with your credentials
npm run dev
```

The backend server runs on `http://localhost:3000`.

### 2. Frontend Setup

In a new terminal window:

```bash
cd frontend
npm install
cp .env.example .env
npm run dev
```

The Vite dev server runs on `http://localhost:5173`.

## API Reference

### Authentication Endpoints

| Method | Endpoint | Description | Auth Required |
| :--- | :--- | :--- | :--- |
| `POST` | `/api/auth/register` | Register a new user (`name`, `email`, `password`, optional `image`) | No |
| `POST` | `/api/auth/login` | Log in with `email` and `password` (sets HTTP-only cookie) | No |
| `GET` | `/api/auth/get-me` | Get currently logged-in user profile | Yes (Cookie) |
| `GET` | `/api/auth/logout` | Clear auth token cookie | No |

### Interview & Strategy Endpoints

All interview endpoints require a valid session token cookie.

| Method | Endpoint | Description |
| :--- | :--- | :--- |
| `POST` | `/api/interview/` | Generate a new interview preparation strategy (accepts `resume` PDF file, `jobDescription`, and `selfDescription`). |
| `GET` | `/api/interview/` | List all previous interview strategy reports generated by the logged-in user. |
| `GET` | `/api/interview/report/:interviewId` | Retrieve detailed interview report (questions, answers, roadmap, skill gaps) by ID. User-scoped. |
| `POST` | `/api/interview/resume/pdf/:interviewReportId` | Generate and stream a downloadable PDF summary report. User-scoped. |
